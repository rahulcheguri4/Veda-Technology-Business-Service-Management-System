# Veda Technology Business & Service Management System
# 📌 Project Overview
● Veda Technology Business & Service Management System is a Python-based application designed to manage the operations of a technology and digital-services organization.
● The system provides features for managing digital services, technology programs, training programs, internships, customer inquiries, and service requests.
● This project demonstrates practical usage of Python programming concepts in a real-world business scenario.

# 🎯 Objectives:
● Manage technology and digital services
● Manage technology programs
● Manage training and internship programs
● Store customer inquiries
● Manage customer service requests
● Search and filter services
● Generate basic business reports
● Store application data using JSON
● Practice Python functions, lists, dictionaries, file handling, and validation

# 🛠️ Technologies Used:
● Python
● JSON
● VS Code / PyCharm
● Git
● GitHub
# ✨ Features
1. Digital Service Management
Users can:
Add new digital services
View available services
Store service description and price
2. Technology Program Management
Users can add and view technology programs with:
Program name
Duration
Description
3. Training Program Management
The application manages training programs including:
Training name
Duration
Trainer name
4. Internship Management
Users can manage internship programs with:
Internship title
Duration
Required skills
5. Customer Inquiry Management
Customer inquiries contain:
Customer name
Email
Subject
Message
Status
Date
6. Service Request Management
Users can create service requests containing:
Customer name
Required service
Request description
Request status
Date
7. Search Functionality
Services can be searched using keywords from the service name or description.
8. Business Report
The system generates a basic report showing:
Number of digital services
Number of technology programs
Number of training programs
Number of internships
Number of customer inquiries
Number of service requests
Pending requests
Completed requests
9. JSON Data Storage
All application data is stored locally in:
data.json
No external database is required.

# ▶️ How to Run
Step 1: Install Python
Make sure Python is installed on your computer.
Check the Python version:
python --version
Step 2: Open the Project
Open the project folder in VS Code.
Step 3: Open Terminal
Run:
python main.py
Step 4: Use the Menu
The application displays:
